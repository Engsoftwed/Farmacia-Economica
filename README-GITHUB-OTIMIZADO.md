# Farmácia Mais Econômica — versão otimizada para GitHub

Este pacote contém os arquivos ativos da loja e do painel administrativo. Foram removidas cópias antigas/duplicadas com nomes como `index (2).html`, `store (26).css` e imagens repetidas, para facilitar o envio pelo GitHub.

## Publicação
- O site pode ser publicado como site estático apontando a raiz deste projeto.
- O painel está em `/admin/`.
- Confira `assets/js/config.js` antes de publicar e configure apenas valores públicos apropriados para o navegador.
- Nunca envie senhas, chaves secretas ou arquivos `.env` ao GitHub.

## Observação sobre limite de arquivos
O repositório GitHub não tem limite geral de 99 arquivos. O envio de vários arquivos pela interface web pode ter limite por operação. Este ZIP foi enxugado para conter somente os arquivos canônicos necessários à loja e ao painel; para projetos maiores, prefira enviar o ZIP extraído com `git push` usando GitHub Desktop ou Git instalado.
